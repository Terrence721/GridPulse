GridPulse — system architecture

One event pipeline, three real add-ons riding on top of it.

A meter reading travels through three Kafka topics and three .NET services before a webhook ever fires. Account/Customer Service sits to the side as a plain REST dependency the pipeline calls into, not a step in the flow. A fourth topic, usage.anomaly.detected, branches off Usage Aggregation into a fourth service, Grid Operations, correlating meters that stop transmitting into real outages and work orders. Two more recent features — Green Button/NAESB ESPI export and Stripe payment collection — attach real HTTP surface onto services that used to be Kafka-only.
